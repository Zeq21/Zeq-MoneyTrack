# Zeq MoneyTrack

Controle financeiro pessoal simples para cadastrar entradas, saídas e visualizar saldo em tempo real.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Cadastro de entradas
- Cadastro de saídas
- Cálculo automático de saldo
- Listagem de movimentações

## Objetivo

Este projeto foi criado como parte dos meus estudos em desenvolvimento web, com foco em praticar HTML, CSS, JavaScript e lógica de programação.
